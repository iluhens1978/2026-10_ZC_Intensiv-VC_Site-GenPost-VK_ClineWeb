# voice.md — настройки голоса генератора постов

Этот файл — «пульт управления» для `app.py`. Здесь описано, каким получается пост.
Программа читает файл заново при каждом нажатии кнопки «Сформировать пост»:
поправили текст → обновили страницу → пост собирается уже по новым правилам.
Перезапускать сайт не нужно.

## Как это устроено

Настройки записаны строками вида `ключ: значение`. Есть два вида блоков:

* `## Общие настройки` — «база» для всех настроений;
* `## Настроение: Название` — блок конкретного настроения. Названия этих блоков
  автоматически попадают на сайт в список «Настроение поста».

Если в блоке настроения настройка не указана — берётся значение из общих настроек.

| Ключ              | Что делает                                             | Варианты                                        |
|-------------------|--------------------------------------------------------|-------------------------------------------------|
| `тон`             | задаёт финальную фразу-подпись поста                   | дружелюбный / уверенный / дерзкий / заботливый  |
| `длина`           | сколько блоков попадёт в пост                          | короткая / средняя / длинная                    |
| `эмодзи`          | сколько эмодзи оставить в готовом посте                | число, `0` — пост совсем без эмодзи             |
| `стиль заголовка` | как оформить первую строку                             | эмодзи + название / вопрос / КАПС / просто      |
| `вступление`      | живая фраза после заголовка (средняя и длинная длина)  | любой текст                                     |
| `хэштеги`         | строка с хэштегами (только для длинной длины)          | #тег #тег                                       |

Строки, которые начинаются с `#`, `>`, `-` или `|`, программа пропускает —
это подсказки для человека, а не настройки.

Что даёт длина поста:

* `короткая` — заголовок, описание (до 180 символов) и цена. Для сторис и быстрых постов.
* `средняя` — заголовок, вступление, описание, цена и финальная фраза.
* `длинная` — всё то же плюс хэштеги. Для постов в сообществе.
