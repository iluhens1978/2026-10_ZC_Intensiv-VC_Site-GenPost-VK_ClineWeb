# voice.md — настройки голоса генератора постов

Этот файл описывает **характер постов**, которые пишет нейросеть.
`app.py` читает его при каждой генерации и превращает настройки в задание для модели,
поэтому после правок достаточно обновить страницу — перезапуск не нужен.

## Как это устроено

Настройки записаны строками вида `ключ: значение`. Есть два вида блоков:

* `## Общие настройки` — «база» для всех настроений;
* `## Настроение: Название` — блок конкретного настроения. Эти названия
  автоматически становятся вариантами в поле «Настроение поста».

Если в блоке настроения настройка не указана — берётся значение из общих настроек.

| Ключ              | Что это значит для нейросети                                  |
|-------------------|---------------------------------------------------------------|
| `тон`             | общий тон и эмоция поста (пишите словами, как для человека)    |
| `длина`           | короткая / средняя / длинная — сколько предложений в посте     |
| `эмодзи`          | сколько эмодзи разрешено во всём тексте (`0` — совсем без них) |
| `стиль заголовка` | эмодзи + название / вопрос / КАПС / просто                     |
| `хэштеги`         | `да` — добавить 3–5 хэштегов в конце, `нет` — без хэштегов      |

Строки, которые начинаются с `#`, `>`, `-` или `|`, программа пропускает —
это подсказки для человека, а не настройки.
