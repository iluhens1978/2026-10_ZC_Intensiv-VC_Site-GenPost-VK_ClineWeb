**Урок1. Простой сайт**

**1.1. Создание первого сайта по простому промпту**
Сгенерируй сайт в стиле сайта Zerocoder.ru

**1.2. Усложняем промпт: сайт с анимацией и стилем**
Чтобы получить более сложный и красивый сайт, составляем подробный промпт. 

Вот что важно включить:
Цель сайта — например: продать курс по вайб-кодингу
Целевая аудитория — для кого этот курс
Стиль и внешний вид — тёмный фон, плавные переходы цветов, большие заголовки, красивые карточки, сложные анимации, градиент
Цвета — можно указать словами или кодами из брендбука
Анимации — плавное появление блоков, эффект при наведении, живой фон с градиентом, свечение кнопок
Адаптивность — сайт должен корректно выглядеть и на телефоне, и на компьютере
Уникальность — не шаблонный сайт, вызывающий желание записаться на курс.

**1.3. Новый проект и промпт для дайджеста**
Конверсионный сайт на Flask. AI-дайджест для новичков. Карточки с кнопкой "Открыть материал". 8–10 готовых карточек. Современный яркий, не шаблонный, тёмный фон, красивые цвета, плавные переходы. Стек: Flask, HTML, CSS, JavaScript. Запуск через python app.py. Сайт должен хорошо выглядеть на телефоне и компьютере. Код должен быть понятным для новичка.

**Урок2. Сайт с функцией — генератор постов для социальных сетей**

**2.1. Генератор по шаблону, без AI (без API)**
Мы задаём роль: 
разработчик на Python является нашим ассистентом. 

Описываем задачу подробно:
Нам нужен интуитивно понятный, визуально приятный сайт на Flask — генератор постов для товара.
Сайт запускается локально.
Без API, без баз данных, код простой и понятный для новичка.
Логика: пользователь добавляет описание товара и нажимает кнопку «Сформировать пост» — сайт собирает готовый текст по шаблону.
Элементы на странице:
поле для названия товара;
поле для описания товара (обязательное, со звёздочкой);
поле для цены или выгоды;
выбор настроения поста;
кнопка «Сформировать пост»;
блок «Готовый пост»;
кнопка «Скопировать пост» — после нажатия показывает сообщение «Пост скопирован».

Дополнительно мы просим создать файл `voice.md` — он будет содержать настройки формирования поста: общий тон, длина поста, количество эмодзи, стиль заголовка. Также просим оставить в коде комментарии, чтобы можно было легко вносить изменения.

Если пользователь не заполнил поле описания товара, сайт должен выводить соответствующее предупреждение.

**Урок3. Интеграция с ВК**

**3.1. Дорабатывем проект и объяснить, как подготовить сообщество ВКонтакте**
Доработай проект: добавь кнопку "Опубликовать пост", пост должен публиковаться в сообществе ВКонтакте, добавь отложенные посты с выбором конкретного времени, добавь функцию сохранения постов в избранное. Также объясни подробно и на простом языке, как подключить мой проект к сообществу ВКонтакте: какие данные нужны, где их взять и куда добавить.

Как исправляем ошибки по ходу работы:
После первой генерации результат может отличаться от ожидаемого — это нормально. Например, поле выбора времени появилось сразу при открытии страницы, а не после генерации поста. Мы описываем проблему ассистенту:
«Сейчас выбор времени для отложенного поста появляется сразу, как открывается сайт. Нужно, чтобы выбор времени был под сгенерированным постом, рядом должна быть кнопка "Опубликовать сейчас", и пользователь сам выбирает: отложенный пост или публикация сейчас».

Затем проверяем новый результат и при необходимости снова описываем ошибку. Такой диалог продолжается до тех пор, пока функционал не заработает корректно.

**3.2. Создаём сообщество и получаем токен**
Сначала просим ассистента ещё раз подробно расписать инструкцию по подключению сообщества ВКонтакте. 

Затем действуем по шагам:

Создание сообщества:
Заходим во ВКонтакте и переходим в раздел «Сообщества»
Нажимаем «Создать сообщество», вводим название, выбираем тематику
Нажимаем «Создать»

Получение токена доступа:
Переходим в созданное сообщество → «Управление» → «Дополнительно» → «Работа с API»
Нажимаем «Ключи доступа» → «Создать ключ»
Выбираем нужные права — нам достаточно «Доступ к стене»
Подтверждаем создание (потребуется подтверждение через телефон)
Копируем полученный ключ

Токен показывается только один раз — сразу скопируйте его и сохраните в надёжном месте. После закрытия страницы он будет недоступен.

Получаем ID сообщества:
ID группы часто виден прямо в ссылке на сообщество в виде цифр. Если в ссылке вместо цифр стоит красивое название — используем сервис regvk.com: вставляем ссылку на сообщество и нажимаем «Определить ID».

Добавляем данные в проект:
Переходим в OpenCode и в чате с ассистентом добавляем:
Ключ доступа ВКонтакте для публикации постов на стене: [ваш токен]
ID группы: [ваш ID]

Пишем: «Добавь мои данные» и отправляем на генерацию.

В учебном проекте допустимо передать данные через ассистента. В реальных масштабных проектах лучше вносить токены вручную, чтобы они не попали в историю чата.

**3.3. Добавляем редактор постов**
Генератор уже работает, но иногда хочется не перегенерировать пост полностью, а лишь немного его скорректировать — добавить символы, сделать переносы строк, уточнить текст.

Добавляем эту функцию отдельным промптом:
Добавь следующий функционал: иконку карандаша, нажав на которую мы сможем редактировать пост. Отредактированный пост сохраняется, и мы можем его опубликовать или отложить в публикацию.

После генерации проверяем: редактируем текст в поле, нажимаем «Сохранить», затем «Опубликовать сейчас» и проверяем в сообществе, что отредактированный вариант попал туда корректно.

Таким же образом можно добавить любой другой функционал: проверку орфографии, подсчёт символов, предпросмотр поста. Каждая новая функция — это отдельный промпт

**3.4. Публикуем проект на сервере**
Используем сервис PythonAnywhere (pythonanywhere.com) — бесплатный способ опубликовать Python-проект.

Шаги:
Переходим на pythonanywhere.com, нажимаем Start (зелёная кнопка)
Выбираем бесплатный тариф для начинающих, регистрируемся (никнейм, email, пароль)
Заходим в аккаунт, закрываем вводный тур
Переходим в раздел Files, удаляем всё лишнее.

Загружаем файлы проекта:
Создаём новую директорию с именем нашего проекта (например, postgeneration-site)
Загружаем в неё основные файлы проекта: app.py и остальные
Создаём вложенную директорию static и загружаем в неё файлы из папки static
Создаём директорию templates и загружаем туда соответствующие файлы.

Структура папок на сервере должна точно повторять структуру папок на компьютере — иначе проект не запустится.

Настраиваем и запускаем веб-приложение:
Переходим в раздел Web → Add a new web app
Выбираем Flask и версию Python 3.13
Указываем путь к файлу приложения: убираем лишнее, оставляем `app.py`
Переходим в Files → открываем `app.py` → копируем список используемых библиотек
Вставляем файл в нейросеть и просим сгенерировать команды для установки всех зависимостей
Переходим в раздел Consoles → Bash
Вставляем полученные команды (`Ctrl+V`), нажимаем Enter — ждём установки библиотек
Возвращаемся в Web, нажимаем зелёную кнопку запуска.
Нажимаем на ссылку сайта — проект работает постоянно.
