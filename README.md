# ПостМастер AI — генератор постов о товаре с нейросетью

Сайт на **Flask**: вы вставляете ссылку на товар с маркетплейса — языковая модель
читает название, описание и фото и пишет живой, оригинальный пост для соцсетей.
Посты получаются разными: каждый раз выбирается новый творческий приём, а эмоцию
задаёт выбор настроения.

![Главная страница](docs/screenshots/desktop.png)

## Что умеет сайт

* поле **«Ссылка на товар»** — обязательное, помечено звёздочкой `*`
  (Ozon, Wildberries, Яндекс Маркет или любой другой магазин);
* сайт сам достаёт со страницы товара **название, описание и главную картинку**
  (из Open Graph-разметки или JSON-LD) и показывает их в карточке товара;
* поле **«Что важно упомянуть»** — необязательное пожелание к посту;
* выбор **настроения поста**: Радостное, Деловое, Дерзкое, Заботливое;
* кнопка **«Сформировать пост»** — текст пишет нейросеть через OpenRouter;
* блок **«Готовый пост»** с количеством символов и кнопкой **«Скопировать пост»**
  (после нажатия появляется сообщение «Пост скопирован»);
* **«Опубликовать сейчас»** — пост уходит на стену сообщества ВКонтакте;
* **отложенная публикация** — под постом выбираете дату и время, и ВКонтакте
  сам опубликует пост в этот момент;
* **«В избранное»** — пост сохраняется в файл `data/favorites.json`
  (без базы данных), ниже появляется карточка «Избранное» с кнопками
  «Опубликовать», «Скопировать» и «Удалить»;
* кнопка **«Сгенерировать другой вариант»** — тот же товар, но другой текст;
* понятные предупреждения: пустая ссылка, неверная ссылка, проблема с ключом,
  лимиты бесплатных моделей, ошибки ВКонтакте.

Стиль постов (тон, длина, эмодзи, заголовок, хэштеги) настраивается в файле
[`voice.md`](voice.md) — без правки кода.

## Что нужно для запуска

1. Python 3.9 или новее.
2. **Ключ OpenRouter** — регистрация и создание ключа: <https://openrouter.ai/keys>
   (бесплатно, ключ выглядит как `sk-or-v1-...`).
3. Модель по умолчанию — `openrouter/free` (Free Models Router): роутер сам выбирает
   одну из бесплатных моделей, поэтому генерация ничего не стоит.
4. *(по желанию)* **сообщество ВКонтакте** и его токен — чтобы публиковать посты.
   Без него сайт работает: кнопки публикации просто неактивны. Как подключить —
   в разделе [«Подключение сообщества ВКонтакте»](#подключение-сообщества-вконтакте).

## Запуск: 4 шага

```bash
# 1. Перейти в папку проекта
cd 2026-10_ZC_Intensiv-VC_Site-GenPost-VK_ClineWeb

# 2. Установить зависимости (Flask и requests)
pip install -r requirements.txt

# 3. Создать файл секретов и вписать ключ
cp .env.example .env      # Windows: copy .env.example .env
#   → откройте .env и вставьте ключ в строку OPENROUTER_API_KEY=sk-or-v1-...

# 4. Запустить сайт
python app.py             # → http://127.0.0.1:5000
```

Остановить сервер: `Ctrl + C` в терминале.

### Запуск прямо на GitHub (Codespaces)

1. На странице репозитория: **Code → Codespaces → Create codespace**.
2. В терминале выполните `pip install -r requirements.txt`,
   затем `cp .env.example .env` и впишите ключ (шаг 3 выше).
3. Запустите `python app.py` и откройте вкладку **Ports → 5000 → Open in Browser**.

> В Codespaces файл `.env` живёт только внутри контейнера и не попадает в git.

## Файл секретов `.env` — где лежит ключ

Ключ API хранится не в коде, а в отдельном файле **`.env`** в корне проекта:

```
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ
OPENROUTER_MODEL=openrouter/free
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1/chat/completions
VK_ACCESS_TOKEN=vk1.a.ваш-ключ-сообщества
VK_GROUP_ID=123456789
APP_URL=http://127.0.0.1:5000
APP_TITLE=PostMaster AI
```

Правила безопасности (важно!):

* `.env` добавлен в `.gitignore` — ключ **не попадает в git** и не уезжает на GitHub;
* в репозитории лежит только шаблон **`.env.example`** без ключа;
* если ключ всё-таки «засветился» — удалите его на <https://openrouter.ai/keys>
  и создайте новый;
* файл читается при каждой генерации, поэтому после вставки ключа достаточно
  обновить страницу — перезапускать сайт не нужно (обновления `voice.md`
  подхватываются так же);

Хотите другую модель — впишите её в `OPENROUTER_MODEL` (например, `openrouter/auto`
или любую модель вида `...:free`). Список: <https://openrouter.ai/models>.

## Подключение сообщества ВКонтакте

Чтобы кнопки «Опубликовать сейчас» и «Отложить» работали, нужны **две вещи**:
токен доступа (ключ) и ID сообщества. Оба значения вставляются в файл `.env` —
больше никуда ничего вписывать не нужно.

### Шаг 1. Создать сообщество (если его ещё нет)

1. Откройте ВКонтакте → раздел **«Сообщества»** (левое меню).
2. Нажмите **«Создать сообщество»**, выберите тип (например, «Бизнес»),
   введите название и тему, нажмите **«Создать сообщество»**.

### Шаг 2. Получить токен доступа

1. Зайдите в сообщество → **«Управление»**.
2. Слева: **«Дополнительно» → «Работа с API»**.
3. Нажмите **«Ключи доступа» → «Создать ключ»**.
4. Отметьте галочками права:
   * **«Доступ к стене»** (`wall`) — чтобы публиковать посты;
   * **«Управление сообществом»** (`manage`) — чтобы публиковать от имени сообщества;
   * **«Доступ в любое время»** (`offline`) — чтобы токен не «сгорал» через сутки.
5. Подтвердите создание (ВКонтакте попросит подтвердить по SMS/через приложение).
6. **Скопируйте ключ** — он показывается один раз. Выглядит примерно так:
   `vk1.a.AbCdEf...` (очень длинная строка).

> Если ключ потерялся — просто создайте новый и удалите старый.
> Ключ нельзя выкладывать на GitHub: он даёт доступ к вашему сообществу.

### Шаг 3. Узнать ID сообщества

* Откройте сообщество → **«Управление»**. В адресной строке будет что-то вроде
  `vk.com/groups?act=edit&gid=123456789` — вот **123456789** это и есть ID.
* Либо откройте любое фото/пост сообщества — в адресе вида
  `vk.com/wall-123456789_42` число после минуса — ID.
* Если в ссылке на сообщество красивое имя (`vk.com/my_shop`), ID можно узнать
  в разделе «Управление» или через сервис `regvk.com`.

Нужны **только цифры**, без минуса: `VK_GROUP_ID=123456789`.

### Шаг 4. Вписать данные в `.env`

Откройте файл `.env` в корне проекта и заполните две строки:

```
VK_ACCESS_TOKEN=vk1.a.ваш_длинный_ключ
VK_GROUP_ID=123456789
```

Затем просто обновите страницу в браузере — настройки читаются при каждом
запросе, перезапуск сайта не нужен.

### Шаг 5. Проверить

1. Сгенерируйте любой пост.
2. Под текстом поста нажмите **«Опубликовать сейчас»**.
3. Появится зелёная плашка «Пост опубликован в сообществе ВКонтакте»
   и ссылка **«Открыть пост во ВКонтакте»**.
4. **Отложенный пост**: выберите дату и время в поле под постом (минимум через
   2 минуты) и нажмите **«Отложить»**. Пост появится в сообществе автоматически —
   ВКонтакте хранит таймер у себя, поэтому сайт может быть даже выключен.
   Время берётся по часам компьютера, на котором запущен сайт.

### Если что-то не работает

| Сообщение сайта | Что это значит |
|---|---|
| «ВКонтакте не подключён» | в `.env` пустые `VK_ACCESS_TOKEN` или `VK_GROUP_ID` |
| «не принял токен (ошибка 5)» | ключ скопирован не полностью или удалён |
| «Нет прав на публикацию (ошибка 15)» | у ключа нет прав `wall` и `manage` — создайте новый ключ с галочками |
| «Неверные параметры (ошибка 100)» | в `VK_GROUP_ID` попали буквы или минус — нужны только цифры |
| «Публикация запрещена (ошибка 214)» | в настройках сообщества запрещены посты от имени сообщества: Управление → Настройки → Основная информация → «Стена» |
| «Время публикации должно быть…» | выбрали время в прошлом — ВКонтакте не умеет публиковать назад |

## Избранное

* Кнопка **«⭐ В избранное»** под готовым постом сохраняет текст в файл
  `data/favorites.json` (папка создаётся сама, база данных не нужна).
* Одинаковые посты повторно не добавляются.
* В карточке «Избранное» можно раскрыть пост, скопировать его, опубликовать
  в сообществе или удалить.
* Файл `data/` добавлен в `.gitignore`: личные посты не уезжают в репозиторий.

## Как это работает внутри

```
ссылка → requests скачивает страницу → og:title / og:description / og:image
       → JSON-LD (если есть) → промпт (данные товара + настройки из voice.md)
       → OpenRouter (openrouter/free) → готовый пост
       → «Опубликовать сейчас» / «Отложить» → ВК API (wall.post)
       → «В избранное» → data/favorites.json
```

Структура проекта:

```
.
├── app.py                 # логика: секреты, разбор ссылки, промпт, ИИ, ВК, избранное
├── voice.md               # настройки стиля: тон, длина, эмодзи, заголовок, хэштеги
├── .env.example           # шаблон файла секретов (копируется в .env)
├── requirements.txt       # Flask + requests
├── templates/index.html   # страница сайта
├── static/css/style.css   # оформление
├── static/js/app.js       # копирование, загрузка, дата публикации
├── data/favorites.json    # избранные посты (создаётся автоматически)
└── docs/screenshots/      # картинки для README
```

В `app.py` семь подписанных разделов:

1. **Секреты и настройки** — `load_secrets()`, `openrouter_config()`, `vk_config()`.
2. **Настройки голоса** — `load_voice()` разбирает `voice.md`.
3. **Данные товара по ссылке** — `load_product()`, `_meta_content()`, `_jsonld_product()`.
4. **Запрос к нейросети** — `build_user_prompt()`, `style_instructions()`, `ask_model()`.
5. **Публикация в ВКонтакте** — `publish_to_vk()`, `parse_publish_time()`.
6. **Избранное** — `load_favorites()`, `add_favorite()`, `delete_favorite()`.
7. **Маршруты** — `index()` (действия `generate` / `favorite` / `publish_now` /
   `publish_later`) и `favorites_delete()`.

### Как настраивается стиль постов

`app.py` превращает настройки из `voice.md` в инструкции для модели:

| Ключ              | Что получает нейросеть                                     |
|-------------------|------------------------------------------------------------|
| `тон`             | эмоция и манера поста, например «тепло и заботливо»        |
| `длина`           | короткая (2–4 предложения), средняя, длинная (2–3 абзаца)  |
| `эмодзи`          | ограничение на количество эмодзи (`0` — без них)           |
| `стиль заголовка` | эмодзи + название / вопрос / КАПС / просто                 |
| `хэштеги`         | `да` — добавить 3–5 хэштегов в конце, `нет` — без них       |

Хотите новое настроение — добавьте блок `## Настроение: Название` в `voice.md`,
и оно сразу появится на сайте.

## Частые вопросы и проблемы

**Маркетплейс не отдаёт страницу (Ozon, Wildberries).**
Это нормально: магазины закрывают доступ роботам. Сайт не падает — он берёт
название из адреса ссылки и сообщает об этом под карточкой товара, а нейросеть
пишет пост по этим данным. Чтобы получить более точный текст, добавьте
уточнение в поле «Что важно упомянуть».

**«Не найден ключ OpenRouter».**
Нет файла `.env` или в нём пустая строка `OPENROUTER_API_KEY=`. Скопируйте
`.env.example` в `.env`, вставьте ключ и перезапустите сайт.

**«OpenRouter не принял ключ (ошибка 401)».**
Ключ скопирован не полностью или уже удалён. Создайте новый на
<https://openrouter.ai/keys>.

**«Слишком много запросов (ошибка 429)».**
У бесплатных моделей есть лимит запросов в минуту/сутки. Подождите минуту
или укажите в `OPENROUTER_MODEL` другую бесплатную модель.

**Пост генерируется 10–30 секунд.**
Так и должно быть: бесплатные модели думают не мгновенно. На кнопке в это время
крутится индикатор, а повторное нажатие блокируется, чтобы не тратить лимит.

**Пост получился странным, с ошибками или пустым.**
`openrouter/free` — роутер: он каждый раз выбирает случайную бесплатную модель,
и их качество разное. Помогает:
* нажать «Сгенерировать другой вариант» (получит ответ уже другая модель);
* добавить подсказку в поле «Что важно упомянуть»;
* выбрать другую модель в `OPENROUTER_MODEL` (например, конкретную `...:free`).

Пустые ответы сайт обрабатывает сам: `app.py` делает до 3 попыток (у «думающих»
моделей весь лимит токенов уходит на размышления, и текст не успевает появиться),
а из готового текста вычищаются ссылки, markdown и служебные символы.

**Пост написан не по-русски или со странными оборотами.**
Это огрехи бесплатной модели. В системном промпте есть запрет на латиницу и
шаблонные рекламные фразы, но 100% гарантии бесплатные модели не дают.

**Кнопка «Опубликовать сейчас» серая.**
ВКонтакте не подключён: пустые `VK_ACCESS_TOKEN` или `VK_GROUP_ID` в `.env`.
Смотрите раздел [«Подключение сообщества ВКонтакте»](#подключение-сообщества-вконтакте).

**Отложенный пост не появился в выбранное время.**
Проверьте: время должно быть минимум на 2 минуты позже текущего; часовой пояс
берётся с компьютера, где запущен сайт; сам пост уже создан в сообществе
со статусом «отложенный» (его можно увидеть в управлении сообществом).
ВКонтакте публикует такие посты сам, сайт для этого держать включённым не нужно.

**Избранное пропало.**
Оно хранится в файле `data/favorites.json` рядом с `app.py`. Если файл удалить
или перенести проект без этой папки — список начнётся заново.

## Публикация в интернете (по желанию)

PythonAnywhere, раздел **Web → Add a new web app → Flask**:

1. Загрузите `app.py`, `voice.md`, `requirements.txt`, папки `templates/` и `static/`.
2. В настройках Web укажите путь к файлу приложения: `app.py`.
3. В консоли Bash: `pip install -r requirements.txt`.
4. Создайте файл `.env` рядом с `app.py` и вставьте ключ (только через файловый
   менеджер PythonAnywhere, не через git).
5. Нажмите **Reload** и откройте ссылку сайта.

## Что дальше

Публикация в ВКонтакте, отложенные посты и избранное уже готовы. Следующий шаг
из методички — **редактор поста** (иконка карандаша: поправить текст перед
публикацией) и подсчёт символов. Код специально разделён на функции, поэтому
новые возможности добавляются без переписывания проекта.
